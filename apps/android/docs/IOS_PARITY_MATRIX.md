# Illumined iOS → Android parity matrix

This document is the acceptance checklist for the Android app. A row is complete only when behavior, data, states, role visibility, and visual presentation have been compared directly with the current iOS app.

## Evidence status

- **Implemented**: present in Android and connected to the shared Firebase project.
- **Partial**: some behavior exists, but direct iOS comparison or important states are missing.
- **Not started**: no Android counterpart exists yet.
- **Blocked on iOS**: exact visual or behavioral parity requires iOS source, screenshots, or an inspectable build.
